# OpenBerth Map

OpenBerth is a GTK application for organizing tmux targets as user-facing TVs and berths.

Start here:

- [[README|OpenBerth README]] covers install, launch, packaging, and day-to-day commands.
- [[openberth_specifications|UI specification]] defines the interaction model.
- [[User Model]] explains TVs, berths, grouping, and selection.
- [[Architecture]] connects the app modules to the product behavior.
- [[Desktop Launch]] covers KDE, taskbar identity, package entry points, and the icon.
- [[Development Workflow]] covers tests, config, and local iteration.

Core relation:

[[User Model]] defines the concepts, [[Architecture]] implements them, [[Desktop Launch]] makes the app easy to start, and [[Development Workflow]] keeps the project shippable.
