# OpenBerth Map

OpenBerth is a GTK application for organizing tmux targets as user-facing TVs and berths.

Start here:

- [OpenBerth README](README.md) covers install, launch, packaging, and day-to-day commands.
- [UI specification](openberth-specifications.md) defines the interaction model.
- [User Model](user-model.md) explains TVs, berths, grouping, and selection.
- [Architecture](architecture.md) connects the app modules to the product behavior.
- [Desktop Launch](desktop-launch.md) covers KDE, taskbar identity, package entry points, and the icon.
- [Development Workflow](development-workflow.md) covers tests, config, and local iteration.

Core relation:

[User Model](user-model.md) defines the concepts, [Architecture](architecture.md) implements them, [Desktop Launch](desktop-launch.md) makes the app easy to start, and [Development Workflow](development-workflow.md) keeps the project shippable.
